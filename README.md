# RestTimer

RestTimer یک تایمر استراحت فارسی برای ویندوز است. پیش‌فرض برنامه ۶۰ دقیقه کار و ۱۵ دقیقه استراحت است.

## اجرا

روی ویندوز ۱۰ یا ۱۱، فایل‌های نسخهٔ اجرایی را در یک پوشهٔ ثابت استخراج کنید و `RestTimer.exe` را باز کنید. برنامه به ‎.NET Framework 4.8 یا بالاتر نیاز دارد.

- شمارش معکوس از زمان اجرا شروع می‌شود. با نگه داشتن نشانگر روی آیکن RestTimer کنار ساعت می‌توانید زمان باقی‌مانده را ببینید.
- هنگام استراحت، بالای مرکز هر مانیتور یک کادر و شمارش معکوس مشترک نمایش داده می‌شود. پس‌زمینه از تصویر محوشده و تیرهٔ همان لحظهٔ صفحه ساخته می‌شود و روی دیسک ذخیره نمی‌شود.
- با پایان شمارش معکوس، انتخاب «رد کردن استراحت» یا زدن `Esc` در کادر استراحت، همهٔ پوشش‌ها بسته می‌شوند و دورهٔ کار بعدی آغاز می‌شود.
- در منوی راست‌کلیک آیکن کنار ساعت، می‌توانید زمان‌ها را با ورودی‌های جداگانهٔ ساعت، دقیقه و ثانیه تغییر دهید، فوری استراحت را شروع کنید یا گزینهٔ «اجرا با ورود به ویندوز» را روشن کنید. تنظیمات برای حساب فعلی ویندوز ذخیره می‌شوند و زمان‌های ذخیره‌شدهٔ نسخهٔ قبلی همچنان قابل استفاده‌اند.

## ساخت از سورس

روی ویندوز با ‎.NET SDK و ‎.NET Framework 4.8 Developer Pack اجرا کنید.

```powershell
dotnet build -c Release
```

فایل‌های `RestTimer.exe` و `RestTimer.exe.config` را کنار هم از پوشهٔ `bin/Release/net48/` اجرا یا توزیع کنید.
